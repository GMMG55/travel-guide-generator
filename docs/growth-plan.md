## 社区文案草稿（尚未对外发布）

### 旅行需求用户

标题：两个人去青岛，如何把4000元预算安排成一份可编辑攻略？

正文：我做了一个旅行规划 Skill。输入出发地、日期、人数和预算，可以生成每日行程、美食、住宿区域和下雨备选，并保存为浏览器能打开的 HTML。青岛案例中可以直接编辑每项时间和费用，刷新保留修改。示例价格用于演示，真实出行前仍需核实。先看 [完整案例](../examples/README.md)，有旅行计划的话欢迎试用并反馈最不合理的一段安排。

配图：桌面攻略、手机行程、预算编辑三张真实截图。主入口为案例页。

### 开发者与 Agent Skills 用户

标题：把AI旅行建议变成文件：行程校验、预算编辑和日历导出

正文：Travel Guide Generator 用结构化 JSON 连接校验器与 HTML/Markdown/ICS/GeoJSON 导出。支持离线生成，网络搜索由宿主提供，高德 Key 可选。项目采用 Agent Skills 格式，并提供 Claude Code 目录安装及 Claude 网页端 ZIP 打包说明；Claude 账户内流程尚待实测。欢迎查看 [源码和安装说明](https://github.com/GMMG55/travel-guide-generator)，反馈宿主兼容问题或实际生成案例。

主入口为仓库。先邀请5–10位有旅行需求的人试用，按重复问题修复流程后再扩大分发。不要批量发帖、互星或承诺增长数字。

## 每周记录

把 [CSV 模板](weekly-metrics.csv) 复制成周报，每周同一天填写。未知数据留空，不填0。下载和安装分别记录，不用两者相除声称转化率。

| 数据 | 来源 | 观察方式 |
| --- | --- | --- |
| 仓库访问、独立访客、克隆及来源 | GitHub Insights / Traffic | 14天窗口，周与周可能重叠，不能简单求和 |
| GitHub Star 总量 | 仓库页面 | 与上次快照比较净变化 |
| ClawHub downloads / installs / stars | ClawHub 页面或CLI | 记录累计值及采集时间，口径可能不同 |
| 首次生成成功人数 | 自愿试用反馈 | 同时记录样本人数，不推算为全体用户成功率 |
| 常见问题 | Issues、试用记录 | 记录出现次数、失败步骤和下一步行动 |

先积累两周基线，再确定目标。访问少则改分发和搜索描述；访问上升但安装反馈少则看首屏与安装步骤；安装成功而生成失败则先修宿主权限、路径或提示流程。

本文件只是手动执行方案，不创建自动化任务，不追踪用户的实际旅行内容。
